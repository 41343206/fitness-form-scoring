# 拍攝角度與 3D 座標的效果（2026-11-13）

## 資料與方法
- 資料：Mendeley kgbb3yn47p v2 的深蹲、伏地挺身，**側面、斜面、正面**三種影片（排除重複／標籤矛盾的影片後，每個角度約 40 支）。
- 用 App 同一套程式（MediaPipe pose_landmarker_lite → 角度 → 計次 → 評分），分別以三種算法計算角度：
  - **純 2D**：畫面座標；
  - **純 3D**：MediaPipe 世界座標（worldLandmarks）；
  - **混合**（App 現行）：依估計的拍攝角度混合，≤ 15° 全用 2D，≥ 45° 全用 3D。
- 估計的拍攝角度：側面中位數 3–6°，斜面 44–48°（範圍 27–74°），正面 87°。資料集沒有 15–30° 的影片。
- **注意**：三個角度是**分開錄的**（不是同一次動作同時拍），所以不能逐下比對。改用兩個不需要逐下配對的指標：
  1. **伸直角度**：站直的膝角、撐直的肘角，實際約 175–180°，量出來越接近越準。
  2. **最低角度**：和同一人、同標籤的側面 2D 結果比。不同次錄影，只能當參考。

## 結果一：角度準不準（每支影片的中位數）

| 動作 | 拍攝角度 | 純 2D 伸直／最低（和側面差） | 純 3D 伸直／最低（和側面差） | 混合（App） |
|---|---|---|---|---|
| 深蹲 | 側面 | 176° / 73°（0°） | 171° / 75°（5°） | 175° / 73°（0°） |
| 深蹲 | 斜面 ~45° | 178° / 110°（**40°**） | 167° / 88°（24°） | 167° / 88°（25°） |
| 深蹲 | 正面 | 179° / 115°（**41°**） | 158° / 74°（**16°**） | 158° / 74°（16°） |
| 伏地挺身 | 側面 | 168° / 83°（0°） | 159° / 99°（**14°**） | 168° / 83°（0°） |
| 伏地挺身 | 斜面 ~45° | 165° / 71°（16°） | 163° / 94°（12°） | 163° / 91°（11°） |
| 伏地挺身 | 正面 | 可見度只有 0.13，關節點幾乎抓不到 | | |

- 斜拍或正拍時，**純 2D 會把深蹲的深度看淺 40°**：蹲到底會被當成半蹲，系統會一直說「再蹲低一點」。
- **3D 座標把誤差降到 16–25°**，但會把伸直的腿看成彎的（正面站直只有 158°）。
- 正側面時純 3D 反而比較差：伏地挺身最低點差 14°。這是因為 3D 深度是估計值。
- 結論：**2D 和 3D 各有擅長的角度，依拍攝角度混合**（App 現行做法）在側面等於 2D、在斜面等於 3D，兩邊都取到較好的那一個。

## 結果二：計次與評分

| 動作 | 拍攝角度 | 完全計不到次數的影片（混合） | 好壞區分 AUC：規則 / DTW（混合） |
|---|---|---|---|
| 深蹲 | 側面 | 2 / 42 | 0.62 / 0.59 |
| 深蹲 | 斜面 | 1 / 42 | 0.74 / 0.70 |
| 深蹲 | 正面 | **28 / 42** | （只剩 139 下，不具代表性） |
| 伏地挺身 | 側面 | 3 / 40 | 0.71 / **0.81** |
| 伏地挺身 | 斜面 | 3 / 40 | 0.67 / 0.71 |
| 伏地挺身 | 正面 | **39 / 40** | — |

- 斜面 ~45° 還能正常計次、評分。
- 正面深蹲計不到次數：3D 把站直的腿量成 158°，沒超過「站起來」的門檻 160°。
- 正面伏地挺身完全不行：身體前後重疊，關節點抓不到。
- 斜面深蹲「判為標準」的比例比側面低（good 40% vs 71%），因為角度還是有誤差，斜拍會比較常被判不標準。

## 結果三：DTW 模板要不要正側面

| 動作 | 側面模板評斜面動作 | 斜面模板評斜面動作 |
|---|---|---|
| 深蹲 DTW AUC | **0.73** | 0.69 |
| 伏地挺身 DTW AUC | 0.67 | 0.71 |

用側面模板評斜面動作，效果和專門用斜面模板差不多。所以**一套正側面模板就夠**，不用每個角度各做一套。模板用正側面最好，因為那是角度量得最準的時候。

## 結果四：正面才看得到的錯誤（膝蓋內夾）
正面深蹲最低點的「兩膝距離 ÷ 兩踝距離」：good 中位數 1.42、bad 1.34，AUC 0.64，區分力弱。原因是資料集 bad 深蹲混了多種錯誤，沒有單獨標膝蓋內夾。


## 更新：斜拍時放寬計次門檻之後（2026-11-13 晚）
3D 會把站直的腿量成 158–167°，所以深蹲、弓箭步的計次門檻改成依 3D 比重放寬：
深蹲「站起來」160° → 全用 3D 時 148°、「蹲下」140° → 130°；弓箭步 155° → 145°、140° → 130°。伏地挺身不變。

| 動作 | 拍攝角度 | 計不到次數的影片 前 → 後 | 每支影片平均次數 | AUC 綜合分 | 判為標準 good / bad |
|---|---|---|---|---|---|
| 深蹲 | 側面 | 2/42 → 2/42 | 11.9 | 0.64 | 71% / 52% |
| 深蹲 | 斜面 | 1/42 → 2/42 | 11.7 | 0.70 | **24%** / 13% |
| 深蹲 | 正面 | **28/42 → 3/42** | 11.9 | **0.81** | 65% / 16% |
| 伏地挺身 | 側面 | 3/40（不變） | 8.9 | 0.78 | 53% / 30% |
| 伏地挺身 | 斜面 | 3/40（不變） | 9.5 | 0.70 | 53% / 28% |

- 正面深蹲現在能正常計次，次數和側面一樣（每支約 12 下）。分得出好壞，最低角度也和側面接近（70° vs 78°）。
- 斜面深蹲計次正常，但 good 動作只有 24% 被判標準，大多是被判節奏、深度不合格。斜面 3D 估計誤差最大，**斜拍深蹲比較容易被誤判不標準**。
- 正面深蹲的 AUC 比側面高，**不能直接解讀成正面比較好**：三個角度是分開錄的，正面那批 bad 動作本身可能比較明顯（例如比較快）。
- 另外試過把 2D→3D 的過渡區間改成 10–30° 或 5–20°，結果幾乎一樣，維持 15–45°。

## 限制
- 三個角度分開錄，比較只能是近似。
- 沒有 15–30° 的實際影片：這段只有先前的模擬測試，偏 30° 時誤差很小。
- 資料集是 15 fps，主要是年輕男性。
