# 健身動作評分（手機網頁）

用手機鏡頭側拍，在瀏覽器內以 MediaPipe Pose Landmarker 偵測關節點，計算關節角度並計次。每一下都會用關節角度規則加 DTW 比對給分並語音回饋。規劃見 `../plan.md`。

## 檔案

## 使用流程

App 的定位是「在家的 AI 教練」：選今天要練什麼 → 照著做、即時語音糾正 → 做完告訴你哪裡要改。

1. **首頁選今日課表**：點動作卡片加入（可以選好幾個，卡片上會標第幾個），用 −／＋ 調目標次數或秒數，按「開始訓練」。上次選的組合會記住。
   動作共七個，都是徒手、在家就能做：深蹲、伏地挺身、弓箭步、棒式（計時）、臀橋、仰臥起坐、靠牆深蹲（計時，需要一面牆）。
2. 用手機支架把手機放好（站著的動作直放、約腰部高度；趴著或躺著的動作橫放在地上）。實測沒有支架很難固定又拍到全身，所以支架是唯一需要的器材。畫面上會出現對應動作的定位框。
3. 走進框內：
   - 外圈**紅色**：位置不對，畫面箭頭和語音會提示「往後退」、「靠近鏡頭」、「移到框框中間」。
   - 外圈**黃色**：已在框內，請擺好預備姿勢（語音會說這個動作的預備姿勢，例如臀橋「請仰躺，膝蓋彎起來腳踩地」）。
   - 外圈**綠色**：預備姿勢維持 1 秒後自動開始，語音說「開始」。
4. **做的當下**：每一下語音報數；有問題時接著講這個動作專屬的提示，例如深蹲「8，蹲太淺了，屁股往後坐，蹲到大腿接近平行地面」、伏地挺身會分辨「腰塌下去了」還是「屁股翹太高」。連續 3 下標準會稱讚一次。上一下的分數綠色是標準、紅色是不標準。
5. **到目標自動結束**：做到目標次數（或秒數）就結束這組，語音唸出總結與最需要注意的地方，並告訴你下一個動作是什麼。提早走出框外 3 秒也會結束（做過至少一下）。
6. **每組的結果**：次數、標準／不標準、平均分數，接著是「要改進的地方」：哪個部位、出現幾下、當下講的提示，以及一段教練說明（為什麼要改、怎麼改）；最下面可以展開每一下的分數與扣分。按「下一個」換下一個動作（鏡頭不用重開），或「再一組」。
7. **今日訓練總結**：課表做完按「看今日總結」，整理每個動作做得如何和要改進的地方。
8. **訓練紀錄存在哪裡**：每做完一組就存進這支手機瀏覽器的 localStorage（最多 30 次訓練），不會上傳；首頁下方的「訓練紀錄」可以再打開。換手機或清除瀏覽器資料就會不見；帳號登入、雲端同步（Firebase）列在未來工作。
9. 錄影頁開啟時螢幕會保持常亮（支援 Wake Lock 的瀏覽器）。

## 評分方式

每一下的分數 = 0.6 × 規則分 + 0.4 × DTW 分（沒有標準動作模板時只用規則分）。節奏的滿分門檻依資料集 good 動作的下蹲時間（第 20 百分位）設定。

| 動作 | 規則（權重） | 滿分 → 0 分 | 語音提示 |
|---|---|---|---|
| 深蹲 | 深度：最低膝角（45） | 90° → 125° | 再蹲低一點 |
| 深蹲 | 軀幹：最大前傾（30） | 45° → 65° | 胸口挺起來 |
| 深蹲 | 節奏：下蹲時間（25） | 0.6 秒 → 0.3 秒 | 下蹲慢一點 |
| 伏地挺身 | 深度：最低肘角（40） | 90° → 125° | 再往下一點 |
| 伏地挺身 | 身體直線：肩–髖–踝最小角度（40） | 165° → 140° | 核心收緊，身體保持一直線 |
| 伏地挺身 | 節奏：下降時間（20） | 0.4 秒 → 0.2 秒 | 慢一點，控制速度 |
| 弓箭步 | 前腳深度：最低前膝角（40） | 95° → 130° | 前腳再蹲低一點 |
| 弓箭步 | 後腳：最低後膝角（25） | 100° → 140° | 後腳膝蓋再往下 |
| 弓箭步 | 軀幹：最大前傾（20） | 20° → 40° | 上半身挺直 |
| 弓箭步 | 節奏：下蹲時間（15） | 0.7 秒 → 0.3 秒 | 慢一點，控制速度 |
| 臀橋 | 抬臀高度：最大髖角（50） | 170° → 150° | 屁股再抬高一點，肩膀到膝蓋成一直線 |
| 臀橋 | 膝蓋角度：最高點膝角離 90° 多少（25） | 15° → 40° | 腳往屁股靠近一點／腳離屁股遠一點 |
| 臀橋 | 節奏：上推時間（25） | 0.6 秒 → 0.25 秒 | 慢慢往上推，不要用甩的 |
| 仰臥起坐 | 坐起幅度：最小肩–髖–膝角（45） | 70° → 100° | 再坐起來一點，胸口靠近大腿 |
| 仰臥起坐 | 躺下控制：躺回去的時間（30） | 0.8 秒 → 0.3 秒 | 躺下時慢慢放，不要直接倒下去 |
| 仰臥起坐 | 膝蓋彎曲：最大膝角（25） | 100° → 140° | 膝蓋彎起來，腳掌踩穩地板 |

表中是語音提示的主要句子，實際句子在 `js/exercises.js`：有些依情況換一句（例如深蹲差很多時說「蹲太淺了，屁股往後坐…」，伏地挺身身體沒打直時分辨塌腰或翹臀），每條規則也有一段結果頁用的教練說明（`tip`）。

弓箭步兩隻腳都會算膝角，彎比較多的那隻當前腳，所以哪隻腳在前都可以。

**棒式**是靜態動作，不計次，改成計時：肩–髖–踝夾角 ≥ 165° 算姿勢正確。畫面大數字是「姿勢正確的秒數」，旁邊是正確比例，每 10 秒語音報時。
姿勢跑掉超過 1 秒會提醒：髖部在肩–踝連線下方說「核心收緊，不要塌腰」，在上方說「臀部放低一點」。
離開框的時間不算；按「結束」顯示「維持 N 秒、姿勢正確 M 秒（百分比）」，以及塌腰、翹臀各佔了幾秒。

**靠牆深蹲**也是計時：膝角 75°–110° 而且背部傾斜 < 20°（貼牆）算正確。姿勢跑掉時分辨「背離開牆」、「蹲不夠低」、「蹲太低」三種提示。

**臀橋**的計次狀態機是「角度往下再回來」，而臀橋是髖角往上打開再放下，所以程式裡的關鍵角度用 360° − 髖角，畫面上仍顯示髖角。

DTW 比對的是每一下的角度曲線（深蹲：膝角＋軀幹前傾；伏地挺身：肘角＋身體直線；弓箭步：前膝＋後膝；棒式不用 DTW），重新取樣成 40 點後和標準動作比對，平均差 25° 約 37 分。
深蹲、伏地挺身的內建模板來自 Mendeley 公開資料集的側面 good 影片（`js/templates.js`，產生方式見 `tools/build-templates.md`）。
弓箭步、臀橋、仰臥起坐目前還沒有資料集，先用程式內建的理想曲線。按「錄標準動作」可以請動作標準的人做 3 下，存成這支手機的模板，會取代內建模板。
DTW 換算分數的寬鬆程度依資料集設定：深蹲 k = 40、伏地挺身 k = 20，讓資料集標準動作的中位數約 85 分。

## 手機沒有正對側面時

角度同時用兩組座標算：2D 畫面座標（正側面時最準）和 MediaPipe 的 3D 世界座標（不受拍攝角度影響，但深度是估計值）。
程式會從左右肩、左右髖的方向估計拍攝角度（畫面左下角顯示），≤ 15° 用 2D，≥ 45° 用 3D，中間依比例混合。
偏離超過 60° 時，語音提醒「請再側身一點」，但不會擋住計次。

## 本機執行

```bash
npm test          # 跑單元測試（需要 Node 18 以上）
npm run serve     # 在 http://localhost:8080 開啟
```

鏡頭只能在 HTTPS 或 localhost 下開啟。要用手機測試，請部署到 GitHub Pages（或 Netlify），再用手機打開網址。

沒有鏡頭時，可以按「或用影片測試」選一段側拍的深蹲或伏地挺身影片。

## 計次門檻（之後用實測資料調整）

「下」的門檻刻意放寬，只擋掉很小的動作；做得夠不夠深由評分判斷。一下總分 ≥ 80 而且沒有任何一項規則被扣太多（沒有語音提示）才算標準。

| 動作 | 關鍵角度 | 「下」 | 「上」 |
|---|---|---|---|
| 深蹲 | 膝角（髖–膝–踝） | ≤ 140° | ≥ 160° |
| 伏地挺身 | 肘角（肩–肘–腕） | ≤ 135° | ≥ 150° |
| 弓箭步 | 前膝角（兩腳中較小的膝角） | ≤ 140° | ≥ 155° |
| 臀橋 | 髖角（肩–髖–膝） | ≥ 163° | ≤ 153° |
| 仰臥起坐 | 髖角（肩–髖–膝） | ≤ 95° | ≥ 115° |
