# 健身動作評分（手機網頁）

用手機鏡頭側拍，在瀏覽器內以 MediaPipe Pose Landmarker 偵測關節點，計算關節角度並計次。目前是第一階段原型：鏡頭、骨架、角度、計次。評分（規則＋DTW）在後續階段加入，見 [docs/plan.md](docs/plan.md)。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 手機版畫面（首頁動作卡片、錄影頁） |
| `img/` | 首頁動作示意圖（SVG） |
| `js/main.js` | 鏡頭/影片、MediaPipe 推論、畫骨架、更新畫面 |
| `js/pose-math.js` | 關節點編號、角度計算、選擇側面、平滑 |
| `js/rep-counter.js` | 計次狀態機（含緩衝區，避免抖動重複計次） |
| `js/exercises.js` | 深蹲、伏地挺身的關鍵角度與門檻 |
| `tests/logic.test.mjs` | 角度與計次邏輯的單元測試 |
| `tests/view-angle.test.mjs` | 模擬手機沒對準側面（0°、30°、45°、60°）的角度測試 |

## 使用流程

1. 第一頁選動作（深蹲 / 伏地挺身），會自動開啟鏡頭進到錄影頁。
2. 手機放好（深蹲直放、伏地挺身橫放），畫面上會出現對應動作的定位框。
3. 走進框內：
   - 外圈**紅色**：位置不對，畫面箭頭和語音會提示「往後退」、「靠近鏡頭」、「移到框框中間」。
   - 外圈**黃色**：已在框內，請擺好預備姿勢（深蹲：側身站直；伏地挺身：撐起、手臂打直）。
   - 外圈**綠色**：預備姿勢維持 1 秒後自動開始，語音說「開始」，之後每一下都會語音報數。
4. 計次中離開框或姿勢不像在做這個動作，進行中的那一下不算；超過 3 秒就語音「暫停」，要重新進框擺好姿勢才繼續。所以擺手機、走位、做完去拿手機都不會被計入。
5. 按「結束」顯示這組次數，按「再一組」重新開始。
6. 錄影頁開啟時螢幕會保持常亮（支援 Wake Lock 的瀏覽器）。

## 手機沒有正對側面時

角度同時用兩組座標算：2D 畫面座標（正側面時最準）和 MediaPipe 的 3D 世界座標（不受拍攝角度影響，但深度是估計值）。
程式會從左右肩、左右髖的方向估計拍攝角度（畫面左下角顯示），≤ 15° 用 2D，≥ 45° 用 3D，中間依比例混合。
偏離超過 60° 時，語音提醒「請再側身一點」，但不會擋住計次。

## 本機執行

```bash
npm test          # 跑單元測試（需要 Node 18 以上）
npm run serve     # 在 http://localhost:8080 開啟
```

鏡頭只能在 HTTPS 或 localhost 下開啟。要用手機測試，請部署到 GitHub Pages（或 Netlify），再用手機打開網址。

沒有鏡頭時，可以按「或用影片測試」選一段側拍的深蹲或伏地挺身影片。

## 目前門檻（之後用實測資料調整）

| 動作 | 關鍵角度 | 「下」 | 「上」 |
|---|---|---|---|
| 深蹲 | 膝角（髖–膝–踝） | ≤ 100° | ≥ 160° |
| 伏地挺身 | 肘角（肩–肘–腕） | ≤ 100° | ≥ 150° |
