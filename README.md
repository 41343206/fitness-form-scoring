# 健身動作評分（手機網頁）

用手機鏡頭側拍，在瀏覽器內以 MediaPipe Pose Landmarker 偵測關節點，計算關節角度並計次。每一下都會用關節角度規則加 DTW 比對給分並語音回饋。規劃見 `../plan.md`。

## 使用流程

1. 第一頁選動作（深蹲 / 伏地挺身 / 弓箭步 / 棒式），會自動開啟鏡頭進到錄影頁。
2. 用手機支架把手機放好（深蹲、弓箭步直放、約腰部高度；伏地挺身、棒式橫放在地上）。實測沒有支架很難固定又拍到全身，所以支架是唯一需要的器材。畫面上會出現對應動作的定位框。
3. 走進框內：
   - 外圈**紅色**：位置不對，畫面箭頭和語音會提示「往後退」、「靠近鏡頭」、「移到框框中間」。
   - 外圈**黃色**：已在框內，請擺好預備姿勢（深蹲：側身站直；伏地挺身：撐起、手臂打直）。
   - 外圈**綠色**：預備姿勢維持 1 秒後自動開始，語音說「開始」，之後每一下都會語音報數。
4. 計次中離開框或姿勢不像在做這個動作，進行中的那一下不算；超過 3 秒就語音「暫停」，要重新進框擺好姿勢才繼續。所以擺手機、走位、做完去拿手機都不會被計入。
5. 每完成一下會語音報數；姿勢有問題時接著說提示，例如「8，再蹲低一點」。
6. 蹲不夠低、推不夠深也會計次，但會判為「不標準」並語音提示。上一下的分數綠色是標準、紅色是不標準。
7. 按「結束」顯示這組次數、標準／不標準各幾下、平均分數和不標準的原因（例如「深度 2、節奏 1」），按「再一組」重新開始。
8. 錄影頁開啟時螢幕會保持常亮（支援 Wake Lock 的瀏覽器）。

## 評分方式

每一下的分數 = 0.6 × 規則分 + 0.4 × DTW 分（沒有標準動作模板時只用規則分）。節奏的滿分門檻依資料集 good 動作的下蹲時間（第 20 百分位）設定。

| 動作 | 規則（權重） | 滿分 → 0 分 | 語音提示 |
|---|---|---|---|
| 深蹲 | 深度：最低膝角（45） | 90° → 125° | 再蹲低一點 |
| 深蹲 | 軀幹：最大前傾（30） | 45° → 65° | 胸口挺起來 |
| 深蹲 | 節奏：下蹲時間（25） | 0.6 秒 → 0.3 秒 | 下蹲慢一點 |
| 伏地挺身 | 深度：最低肘角（40） | 90° → 125° | 再往下一點 |
| 伏地挺身 | 身體直線：肩–髖–踝最小角度（40） | 165° → 140° | 核心收緊，身體保持一直線 |
| 伏地挺身 | 節奏：下降時間（20） | 0.4 秒 → 0.2 秒 | 慢一點，控制速度 |
| 弓箭步 | 前腳深度：最低前膝角（40） | 95° → 130° | 前腳再蹲低一點 |
| 弓箭步 | 後腳：最低後膝角（25） | 100° → 140° | 後腳膝蓋再往下 |
| 弓箭步 | 軀幹：最大前傾（20） | 20° → 40° | 上半身挺直 |
| 弓箭步 | 節奏：下蹲時間（15） | 0.7 秒 → 0.3 秒 | 慢一點，控制速度 |

弓箭步兩隻腳都會算膝角，彎比較多的那隻當前腳，所以哪隻腳在前都可以。

**棒式**是靜態動作，不計次，改成計時：肩–髖–踝夾角 ≥ 165° 算姿勢正確。畫面大數字是「姿勢正確的秒數」，旁邊是正確比例，每 10 秒語音報時。
姿勢跑掉超過 1 秒會提醒：髖部在肩–踝連線下方說「核心收緊，不要塌腰」，在上方說「臀部放低一點」。
離開框的時間不算；按「結束」顯示「維持 N 秒、姿勢正確 M 秒（百分比）」。

DTW 比對的是每一下的角度曲線（深蹲：膝角＋軀幹前傾；伏地挺身：肘角＋身體直線；弓箭步：前膝＋後膝；棒式不用 DTW），重新取樣成 40 點後和標準動作比對，平均差 25° 約 37 分。
深蹲、伏地挺身的內建模板來自 Mendeley 公開資料集的側面 good 影片（`js/templates.js`，產生方式見 `tools/build-templates.md`）。
弓箭步目前還沒有資料集，先用程式內建的理想曲線。按「錄標準動作」可以請動作標準的人做 3 下，存成這支手機的模板，會取代內建模板。
DTW 換算分數的寬鬆程度依資料集設定：深蹲 k = 40、伏地挺身 k = 20，讓資料集標準動作的中位數約 85 分。

## 手機沒有正對側面時

角度同時用兩組座標算：2D 畫面座標（正側面時最準）和 MediaPipe 的 3D 世界座標（不受拍攝角度影響，但深度是估計值）。
程式會從左右肩、左右髖的方向估計拍攝角度（畫面左下角顯示），≤ 15° 用 2D，≥ 45° 用 3D，中間依比例混合。
偏離超過 60° 時，語音提醒「請再側身一點」，但不會擋住計次。

## 本機執行

```bash
npm test          # 跑單元測試（需要 Node 18 以上）
npm run serve     # 在 http://localhost:8080 開啟
```

鏡頭只能在 HTTPS 或 localhost 下開啟。要用手機測試，請部署到 GitHub Pages（或 Netlify），再用手機打開網址。

沒有鏡頭時，可以按「或用影片測試」選一段側拍的深蹲或伏地挺身影片。

## 計次門檻（之後用實測資料調整）

「下」的門檻刻意放寬，只擋掉很小的動作；做得夠不夠深由評分判斷。一下總分 ≥ 80 而且沒有任何一項規則被扣太多（沒有語音提示）才算標準。

| 動作 | 關鍵角度 | 「下」 | 「上」 |
|---|---|---|---|
| 深蹲 | 膝角（髖–膝–踝） | ≤ 140° | ≥ 160° |
| 伏地挺身 | 肘角（肩–肘–腕） | ≤ 135° | ≥ 150° |
| 弓箭步 | 前膝角（兩腳中較小的膝角） | ≤ 140° | ≥ 155° |
